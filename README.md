# 离心机转子配平规划器 (Centrifuge Rotor Balance Planner)

在给定**转子槽位角度、试管质量、禁用槽位与锁定试管**约束下，搜索近似最优的对称布局，
计算**一阶不平衡量（离心合力/合力矩）与二阶不平衡量**，对锁定试管执行**增量重排**，
逐步**解释每个配对依据**，支持**方案回放**与**JSON 导出**；并对已保存方案做**只读的
称重误差校核**——在逐管独立误差区间内精确求解最不利一阶不平衡量（zonotope 顶点扫掠，
不枚举组合、不把误差绝对值直接相加），对照标称值判定是否超限。

技术栈：Python 3.11 · FastAPI · SQLite · 原生 HTML/CSS/JS（无前端构建）· Docker Compose。

## 端口与配置

| 项目 | 默认值 | 说明 |
| --- | --- | --- |

| 一阶权重 w₁ | 1.0 | 一阶不平衡量（主导离心合力）权重 |

## 使用流程

1. **转子参数**：设置槽位数与半径/转速，点“按槽位数生成均布角度”，也可逐槽改角度；
   在左侧表格或转子图上切换槽位**启用/禁用**。
2. **试管清单**：录入编号与质量（g）；需要固定的试管勾选“锁定”并选择固定槽位。
3. **计算配平方案**：后端在质量与角度约束下做多起点构造 + 模拟退火 + 爬山局部搜索，
   极小化 `w₁·|U₁|² + w₂·|U₂|²`。
4. 查看右侧**合力矩、二阶不平衡量、评级**，以及转子图上的合力向量（蓝=U₁，绿=U₂）。
5. **配对依据**标签页解释每一对对径/近对径试管的质量差、夹角与对消比例；
   无搭档的试管说明其补偿方式。
6. **方案回放**：用滑块/播放键逐步回放构造与微调过程，每步显示当时的 U₁/U₂ 与文字理由。
7. **增量重排**：先算出方案；增删试管或新增锁定后勾选“基于当前结果做增量重排”再计算。
   系统沿用上一方案中仍有效的摆放，仅重放受影响的试管，并标注“已移动”。
8. **导出 JSON / 历史方案**：保存到 SQLite，可再次载入、导出或删除。
9. **方案比较**：在“历史方案”中勾选两条已保存方案，点“比较选中的两条方案”，
   即可按试管编号合并摆放明细（新增 / 移除 / 换槽 / 未变），并并列查看两方案的
   一阶、二阶不平衡量及差值（B − A）。若两方案的转子几何或求解输入（转速、权重、
   试管清单等）不同，比较视图会显著提示参数差异——此时指标差值**不是同条件优化对比**，
   不能仅凭差值评判优劣。
10. **称重误差校核（只读）**：在“历史方案”点“称重校核”，或对当前已保存结果点
    “称重误差校核”。表单直接读取方案的**固定落槽与逐槽角度**（不重新布局），可
    逐管填写**非负质量误差上界 ±εₖ（g，不超过该管标称质量，保证实际质量非负）**，
    以及一个一阶不平衡量限值（g·mm，可空）。提交后服务端在各管误差 δₖ∈[-εₖ,+εₖ]
    **独立正负变化**的区间上求**精确最不利 |U₁|** 及一组达到该值的实际质量，并以
    最不利值判定是否超限，同时并列展示标称值与“标量相加粗略上界”作对照。校核
    **只读、不写库、不覆盖原方案**。

### 最不利 |U₁| 是怎么精确求出来的

实际一阶不平衡量（除以半径 R）为

```
U₁/R = Σ (mₖ + δₖ)·e^{iθₖ} = S₀ + Σ δₖ·e^{iθₖ},   δₖ ∈ [-εₖ, +εₖ]
```

误差集合 `{Σ δₖ e^{iθₖ}}` 是平面上的 **zonotope（二维中心对称多胞体）**；`|·|` 是凸函数，
凸函数在凸多胞体上的最大值必在顶点取得，而顶点处每个 δₖ 都取端点 ±εₖ。对给定最不利方向 φ：

```
δₖ(φ) = εₖ · sign(cos(θₖ − φ))
```

符号只在 `φ = θₖ ± 90°` 处翻转，共至多 2n 个翻转点，把圆周划分为至多 2n 个区间；
逐区间取中点构造对应顶点并比较模长，即得精确最大值，复杂度 **O(n²)**，
**不枚举 2ⁿ 种组合**。注意：把各管误差绝对值直接相加（`标称|U₁| + ΣR·εₖ`）是把向量模
按标量相加，等价于假设所有误差向量严格同向，通常**显著过保守**，页面仅将其列为对照。


## 物理模型

单面转子、所有试管位于同一半径 R：

- 一阶不平衡量（质径积）：`U₁ = R·Σ mₖ·e^{iθₖ}`，单位 g·mm
- 二阶不平衡量：`U₂ = R·Σ mₖ·e^{i·2θₖ}`，单位 g·mm
- 离心合力：`F = ω²·|U₁|·1e-6`（N，g·mm → kg·m）
- 合力矩：`M = F·R/1000`（N·m）
- 等效偏心距：`e = |U₁| / Σm`，评级 A ≤1μm，B ≤5μm，C ≤20μm，D >20μm

## HTTP API 摘要

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/plan` | 提交槽位/试管/参数求解；请求体见 `/docs`，返回结果并可落库 |
| GET | `/api/plans?limit=` | 历史方案列表（含关键指标） |
| GET | `/api/plans/compare?a=&b=` | 比较两条已保存方案：摆放明细合并标注、指标并列与差值、参数差异 |
| GET | `/api/plan/{id}/error-check/form` | 称重误差校核表单只读上下文：固定落槽/角度、标称质量与标称 \|U₁\| |
| POST | `/api/plan/{id}/error-check` | 称重误差校核(只读)：精确最不利 \|U₁\|、对应实际质量、限值判定 |
| GET | `/api/plan/{id}` | 获取某方案完整请求与结果（含回放步骤） |
| GET | `/api/plan/{id}/export` | 下载该方案 JSON |
| DELETE | `/api/plan/{id}` | 删除方案 |
| GET | `/api/config` | 默认参数与物理量说明 |

`POST /api/plan` 增量重排时传入 `previous: [{tube_id, slot}, ...]`（并可带 `parent_id`）。
返回 JSON 顶层含 `metrics / placements / slot_state / pairs / singletons / steps / summary`。

`POST /api/plan/{id}/error-check` 请求体：

```json
{
  "error_bounds": [
    {"tube_id": 1, "error_bound_g": 0.5},
    {"tube_id": 2, "error_bound_g": 0.0}
  ],
  "limit_g_mm": 500.0
}
```

`error_bounds` 逐管给出非负质量误差上界（缺省/0 表示该管无误差），服务端校验
`0 ≤ error_bound_g ≤ 标称质量`；`limit_g_mm` 可省略（只计算不判定）。响应含
`nominal`（标称 \|U₁\|/F）、`worst_case`（最不利 \|U₁\|/方向/F 及一组实际质量
`actual_masses_g`）、`tubes[]`（逐管 ±ε、符号、实际质量与偏差）、
`naive_scalar_bound_g_mm`（标称|U₁|+ΣR·ε 的过保守粗略上界，仅对照）与
`verdict`（`nominal_pass / worst_case_pass / margin_g_mm`）。校核只读，不落库。
